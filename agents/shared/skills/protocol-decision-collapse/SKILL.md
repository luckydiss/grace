# Skill: protocol-decision-collapse

## Purpose
Reduce uncontrolled initiative during blueprinting.

## MANDATORY RULES
- If the task is strategically ambiguous, surface 2-3 bounded options first.
- Make tradeoffs explicit and short.
- After human choice or artifact decision, collapse to a single direction.
- Do not continue synthesis while preserving hidden `OR` branches in your reasoning.

## Output rule
- Canonical artifacts must not contain unresolved architectural `OR`.
