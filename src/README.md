# GRACE Source Surface

Планируемые зоны реализации:
- `state/` — typed workflow state, transition events, persistence adapters
- `graph/` — LangGraph product workflow
- `policies/` — actor permissions, guards, transition policy
- `validators/` — artifact, scope, approval, traceability, retry guards
- `executors/` — bounded architect/coordinator/coder adapters
- `cli/` — entrypoints для workflow transitions и verification
