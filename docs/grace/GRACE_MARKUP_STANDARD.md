# GRACE Markup Standard

`GRACE` использует адресуемые семантические якоря для навигации и безопасных AI-изменений.

Базовые уровни:

- `UC` — use case
- `MC` — module contract
- `FC` — function contract
- `BA` — block anchor

Минимальные правила:

- якоря должны быть стабильными
- ссылки между артефактами должны быть явными
- изменения должны привязываться к `FC` и `BA`
- process artifacts и execution evidence должны быть traceable
