# Coder Work Order Templates

Use these templates when a product needs a coordinator-issued implementation surface that is trace-aware from day one.

- `CoderWorkOrder.template.xml`
  Canonical `CWO` template with `traceId`, handoff linkage, scope refs, and living-document obligations.

Every trace-aware product should keep the same delivery trace across:

- handoff
- coordinator work order
- execution artifacts
- execution skill-trace artifacts
- W11 autonomy artifacts
